    How to play

    Each round is a passage from a Wikipedia article about a place or an event. Every mention of where it is has been blacked out — and for events, every year too.

    1. Pin the map where you think it is.
    2. Set the year it happened (events only). Type 480 BC or use the slider.
    3. Stuck? Reveal another paragraph — each one lowers the most you can score that round.

    Up to 5,000 points for distance and 5,000 for time. Place-only rounds score distance ×2. Five rounds per game; the Daily set is the same for everyone.
